#### 1.平台架构介绍
VUI天眼精灵（VUTIYJL-agent）是一款 CodeAgent + GUIAgent 一体化智能Agent框架，具备大型企业级GUI自动化能力，在功能覆盖和操作方式上具有明显优势。它既能通过代码精准调用系统底层能力，又能模拟人类视觉与操作方式，实现对各类图形界面的智能交互（涵盖PC桌面、ADB安卓设备及各类Web/客户端UI），同时对弹窗关闭、账号验证等常见场景也进行了适配支持，实现广泛的界面操作能力。该框架专为非深度编程的日常办公与业务运营场景设计，以低门槛、高覆盖的特性，将多数重复性、流程化的数字劳动转化为无人值守的自动化任务，是个人效率提升与企业轻量级RPA的理想选择。联系邮箱refuel8@163.com，12小时内必定回复（且长期有效支持消息发送），支持Bug反馈、安全建议与使用咨询交流。

#### 5.推荐多模态大模型
建议选用主流高性能多模态大模型（如vLLM等）。不同厂商的更新迭代速度较快，具体版本请自行测试并参考官方最新公告。

自定义模型需满足条件：代码编写、GUI识别、图片理解、Json响应、openAPI兼容的vLLM大模型。模型性能直接影响自动化效果，建议优先选用高性能版本。
